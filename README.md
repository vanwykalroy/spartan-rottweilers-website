# Spartan Rottweilers — Website Design & Development

A WordPress website built for a Rottweiler breeding kennel, designed to help the client showcase available litters, share their kennel's story, and make it easy for prospective buyers to get in touch.

**Live site:** spartanrottweilers.co.za *(currently in development — not yet public)*
**Status:** 🚧 In progress

---

## Project Brief

The client came in with two draft pages and no defined structure. This project covers full site planning, design, and build — from a discovery questionnaire through to launch.

### Client Goals
- Promote the kennel and advertise available puppies
- Build clientele and make it easy to start an inquiry
- Present the kennel as warm, trustworthy, and family-friendly — not corporate

### Target Audience
- First-time dog owners / new puppy buyers
- Experienced dog owners / breed enthusiasts
- Existing clients looking for updates

### Site Structure
- Home
- About Us
- Males
- Females
- Puppies
- Gallery
- Links
- Contact Us

### Key Features
- Standard contact form
- Direct WhatsApp chat button
- Dynamic "Available Litters" listing area
- Gallery with individual descriptions per dog
- Mobile-responsive design
- Social media links

### Design Direction
Warm & homey — inviting, approachable, trustworthy. Reference sites: craffenheimrottweilers.co.za, earlantonius.com.
